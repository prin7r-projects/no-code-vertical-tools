# 08 — Marketing Strategy

## Positioning (one sentence)

**TradeToolset is a catalog of vertical-specific no-code tools — one tool per niche pain point, $39 a month, install Tuesday, cancel any time.**

The category is *catalog of micro-tools*. Not "no-code platform" (we're a layer on top of platforms). Not "no-code agency" (we're not selling labour). Not "vertical SaaS" (we're not selling a 30-feature suite).

## Messaging hierarchy

### Hero
- **Primary line**: *No-code, but only the tools that work for one trade.*
- **Sub**: a paragraph that explicitly contrasts with "build anything," names two trades, names $39, names cancel-any-time.
- **CTA pair**: `Browse the 8 tools` (primary, anchor to catalog) + `See what's inside one` (secondary, anchor to anatomy).

### Catalog peek (the headline section)
- **Lead-in**: `CATALOG · 7 LIVE / 1 DRAFT`.
- **Heading**: *The shelf, on display.*
- **Sub**: a paragraph that explains every tool is a working no-code template, branded, wired to existing tools.

### Tool anatomy
- **Lead-in**: `TOOL ANATOMY · TT-HVAC-002 · WORKED EXAMPLE`.
- **Heading**: *What's actually inside a TradeToolset tool.*
- **Sub**: a paragraph that says every tool has the same six pieces; only the names of the parts change.

### Pricing
- **Lead-in**: `PRICING · USDT · USDC · BTC · CARD ON-RAMP`.
- **Heading**: *Three tiers. Crypto first.*
- **Sub**: a paragraph that explains the no-card-required-trial posture and the 30-day refund.

### Builder
- **Lead-in**: `FOR BUILDERS · TT-PLAN-X · 70 / 30`.
- **Heading**: *We pay 70% to vertical operators who publish.*

### FAQ
- **Lead-in**: `FAQ · 8 QUESTIONS THAT ACTUALLY GET ASKED`.
- **Heading**: *The straight answers.*

The hierarchy is intentionally **catalog first, slogan second**. The hero subline is shorter than the catalog grid; the catalog grid does the persuasion.

## Content pillars (Wave 2 first 90 days)

### Pillar A — Tool launch posts (1 / month)

A short Indie Hackers + X post per new tool added to the shelf. Format:
- New SKU + vertical + one-line promise
- Screenshot of the artifact (the PDF / the SMS / the Slack alert)
- Price ($39)
- Builder credit (if applicable)
- Link to catalog

No marketing language. Treat it like a hardware-store window display.

### Pillar B — Vertical playbooks (1 / quarter)

A free-to-download 40-60 page PDF for each vertical. Example: *The HVAC operator's playbook: 8 workflows that hurt and the order to fix them.* Sponsored by TradeToolset, distributed through:
- Trade-association newsletters
- The relevant FB groups (the moderator gets it before anyone else)
- The catalog page itself (PDF download in exchange for an email)

Each playbook ranks the workflows by ROI and slots in the relevant TradeToolset SKUs at the right rank — but the playbook is honest enough to say "for this workflow, hire a freelancer; for that one, our SKU fits."

### Pillar C — Builder spotlight (every other tool launch)

Short interview with the builder behind a published tool. Format: 5 questions, 800 words, photo of the builder's workspace. Distributed on Indie Hackers and X.

### Pillar D — Refund-rate transparency (quarterly)

We publish the refund rate per vertical and per tool every quarter. Honest data. This is unusual and earns trust.

## Go-to-market sequence summary

Detailed in `docs/09-go-to-market.md`. The 90-day sketch:

- **Week 1-2**: Wave 2 landing live; 8-tool catalog visible; first 6 install calls scheduled with FB-group moderators.
- **Week 3-6**: First sponsored newsletter slot per vertical; first reddit answer-author thread in `/r/HVAC` and `/r/dentistry`.
- **Week 7-12**: First builder application response; first builder tool ships; vertical playbook v1 (HVAC) drops.

## Tone-of-voice quick reference

(Same as `docs/01-brand-identity.md` voice section, restated for marketers.)

- Use mono labels for prices, SKUs, and status.
- Use plain trade nouns, not euphemisms (`tonnage`, not "system size"; `n_seat`, not "guest capacity"; `no-show`, not "missed appointment").
- Pricing is always visible. Calls are always optional, never required.
- Refund policy is always one sentence away from the CTA.
- We don't say "we're excited to announce." We say "TT-DENT-009 ships Friday."

## Anti-patterns to avoid

- **Don't write the "manifesto."** No 1,200-word page about "the future of no-code." Catalog speaks for itself.
- **Don't AB-test the hero.** The catalog-first hero is a brand commitment; testing erodes it.
- **Don't add "free trial" CTAs.** The first month is the trial.
- **Don't pad the FAQ.** 8 questions, the ones buyers actually ask. Removing two real ones to add three speculative ones is a regression.
- **Don't write a dedicated pricing page.** Pricing lives on the landing alongside the catalog. A separate `/pricing` URL fragments the message.

## Brand drift signals to watch

If any of the following appear in our own output, we've drifted and should hold:
- Hero copy mentioning "AI" before mentioning "tool"
- A "platform" page (we are not a platform)
- A "for everyone" message (we are for trades)
- A "build anything" or "infinite possibilities" line (this is the no-code rainbow we explicitly rejected)
- More than two adjectives in any headline
